# Speedtest Exporter

Simple **Speedtest exporter** for **Prometheus** written in **Golang** using:
- unofficial speedtest.net library [speedtest-go]https://github.com/showwin/speedtest-go
- unofficial Cloudflare library [cloudflare-speed-test](https://github.com/bruceharrison1984/cloudflare-speed-test/tree/main)
